# 图片发送核验待修复

- 状态：未解决；按用户要求于 2026-10-04 临时绕过图片结果核验。
- 适用：福格微信助手 1.0.0，微信 Windows 客户端 4.1.13.65。
- 现象：图片已出现在聊天中，但正式 GUI/Agent 路径无法稳定核对，导致显示结果未知。普通文件的文件名核验不能直接用于图片气泡。

## 临时行为

可识别的图片先检查粘贴草稿，发送仅触发一次；发送动作正常返回且输入框清空后，界面按成功处理，只显示“发送成功”，不显示跳过核验的提示。这不代表已核验接收或实际送达。

内部结果保留 `verified=false`、`verificationSkipped=true`，诊断快照记录 `IMAGE_VERIFICATION_SKIPPED`。不再为图片发送执行聊天气泡内容比对、右键菜单复制或剪贴板像素比对，避免核验动作影响微信交互。

图片无法粘贴、文件不存在、剪贴板写入失败、发送触发异常或输入框未清空时，仍保留失败或未知结果，不报成功。普通文件和文本继续原有核验。发送边界及防重复规则不变，不自动补发图片。

## 后续修复

需要通过真实 GUI → Named Pipe → Agent 路径建立可靠的图片发送证据，覆盖连续独立任务、图片/文件混合发送及异常场景。不能用独立探针成功替代软件验收，也不能仅靠成功标签证明送达。完成前，本问题及完整发布验收门禁均保持未完成。
