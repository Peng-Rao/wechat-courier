# 福格微信助手交互样例

直接打开 `index.html`，无需服务器、安装依赖或网络。资源均位于本目录中。

这是独立 HTML 样例，不加载现有 Python/QML，不连接微信，不读取进程、数据库或真实联系人。
主题、侧栏与参数保存到浏览器的 `fuge-ui-preview-v1` 本地设置中，不修改正式软件的 QSettings。

## 可操作内容

- 三个工作区，216px/64px 可折叠侧栏，浅色与深色外观。
- 名单和消息独立滚动、称呼插入、附件选择/拖入/移除、图片预览与放大。
- 200 条虚构好友记录；导入零选择、区间替换选择、超限拒绝、手动勾选。
- 单击定位、双击或 Enter 编辑；Enter/失焦保存，Escape 取消；可自定义后缀。
- 中文文本与表格右键菜单，键盘导航，复制粘贴、撤销重做、行新增删除。
- 联系人搜索、类型筛选、排序、单元格复制、取消与重新读取、导出确认。
- 两类模拟任务共用累计计时、等待倒计时、暂停/继续、停止与安全收尾。
- 监控页“故障场景”提供搜索失败、未知结果与频繁限制；频繁限制停止整批并定位原行。
- 设置自动保存、间隔联动、批次调整、运行锁定；外观在运行时仍可修改。

联系人读取、申请、消息发送和导出均为模拟。非图片附件只显示选择反馈，不调用 Windows 文件关联。
“下载模板”仅下载包含虚构数据的 CSV。主动选择的本地图片仅使用浏览器临时 URL，不上传。
剪贴板可能受浏览器权限限制，无法读取时会提示使用 Ctrl+V。
