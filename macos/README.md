# 福格微信助手 · macOS 基础版

在 `codex/macos-version` 分支开发，原生 SwiftUI 界面，最低 macOS 14。
此版本先对齐三个工作区及本地基础功能。真实消息群发、好友提交和微信数据库读取尚未实现，相关入口明确禁用。

## 已实现

- **消息群发工作区**：逐行名单、去重、TXT/CSV 名单导入、`{name}` 模板、逐人预览、附件整理与打开、本地内容校验。
- **好友申请工作区**：CSV（UTF-8 / GB18030）和 XLSX 首个工作表导入；姓名、账号、行内打招呼语编辑；内置及自定义后缀；全局模板；空值与重复账号提示；区间选择；每批 1–1000 人限制；申请计划 CSV 导出。
- **联系人工作区**：CSV/JSON/XLSX 导入，兼容 Windows 版联系人字段；关键词筛选、特殊账号过滤、列排序；导出当前筛选结果为 CSV、JSON 或 XLSX；选中联系人可加入群发名单。
- **本地演练与记录**：冻结当前任务内容，按间隔校验，支持暂停、继续、停止；暂停不计时；导出记录；异常退出的进行中记录恢复为停止，越过外部操作边界的记录恢复为未知，不自动重放。
- **macOS 集成**：原生侧栏、菜单快捷键、独立设置窗口、系统/浅色/深色主题、独立只读微信环境检测进程、可直接打开的 `.app`。

“本地演练 / 预检通过”仅表示内容校验通过，不代表消息或好友申请已发送，也不核验账号是否真实存在。联系人来自用户导入文件；该版本不读取微信的数据库或内存。

## 构建与运行

需要 Xcode 或提供 macOS SDK 的 Apple 开发工具，无第三方 Swift 包依赖。

在仓库根目录运行：

```sh
./script/build_and_run.sh           # 构建、生成 .app 并启动
./script/build_and_run.sh --build   # 仅构建和打包
./script/build_and_run.sh --verify  # 构建、启动并确认进程
swift test --package-path macos     # 核心单元测试
```

应用生成于 `dist/FugeWeChat.app`。默认编译当前机器架构；本次在 Apple Silicon 验证。产物使用本机临时签名，面向公开分发还需要 Developer ID 签名和公证。

支持 `--debug`、`--logs`、`--telemetry` 运行选项。Codex 项目运行按钮指向同一脚本。

快捷键：`⌘1` 消息、`⌘2` 好友、`⌘3` 联系人、`⌘4` 记录；`⇧⌘R` 消息本地演练；`⇧⌘P` 暂停/继续；`⌘.` 停止；`⌘,` 参数设置。

## 文件与隐私

- 联系人、收件人和消息草稿保存在当前应用会话中，关闭应用后不保留。仅设置和运行记录持久化。
- 运行记录位于 `~/Library/Application Support/FugeWeChatMac/runs.json`，含目标、时间、状态，不含消息正文。目录权限 0700，文件权限 0600。
- JSON 沿用 Windows 字段：`nick_name`、`remark`、`phone`、`username`、`alias`、`description`、`category`；同时支持 macOS 内部字段名导入。号码必须是字符串以保留前导零。
- CSV 导出对公式开头的内容加单引号；XLSX 使用文本单元格，冻结表头并提供筛选。JSON 保留原文。导出使用系统保存对话框和原子写入；文件存在时由系统确认替换。
- XLSX 首个工作表支持共享字符串、内联字符串和缓存值；不执行公式。数字单元格若在原文件中已丢失前导零，导入无法恢复，请将账号列设为文本。
- 检测进程只读取微信安装信息、运行状态和辅助功能控件类型数量，不读取聊天文字、不改变微信窗口、不触发发送、不自动申请辅助功能权限。

## 微信适配现状与下一阶段

本机 Mac 微信 4.1.13 已登录，但当前辅助功能树只显示窗口及菜单，没有暴露聊天、搜索和输入控件。
此基础版不会通过固定坐标猜测收件人或发送。独立 Agent 目前只接受 `--inspect`，其他命令明确拒绝。

后续需要依次完成：

1. 实机识别辅助功能控件的可用条件及支持版本；验证搜索、唯一结果和聊天标题回读。
2. 文本/附件写入与回读、发送边界持久化、发送结果核验，再开放消息发送。
3. 好友资料和账号核验、备注与打招呼语回读、用户确认及提交结果核验，再开放好友提交。
4. macOS 微信联系人数据库格式与只读获取方式适配，验证数据来源和导出完整性。
